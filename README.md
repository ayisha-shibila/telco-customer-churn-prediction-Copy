
# Telco Customer Churn Prediction

## Project Overview
This project focuses on analyzing customer churn in the telecommunications industry using Python and Machine Learning.

The objective is to understand customer behavior, identify factors influencing customer churn, and predict whether customers are likely to leave the company.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Feature Encoding and Preparation
6. Machine Learning Model Building
7. Model Evaluation

## Key Analysis
- Analyzed customer demographics and service usage.
- Explored churn patterns across different customer groups.
- Examined the relationship between contract types and churn.
- Investigated factors that may influence customer retention.

## Machine Learning
Applied classification techniques to predict customer churn and evaluated model performance.

## Project File
- `telco_customer_churn.ipynb` – Contains the complete Python code, data analysis, visualizations, and machine learning workflow developed using Google Colab.

## Conclusion
This project provided practical experience in data cleaning, exploratory data analysis, data visualization, and machine learning-based customer churn prediction.
